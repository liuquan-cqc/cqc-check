# 报告同步与企业核验助手（Edge）

本扩展用于在 Microsoft Edge 中选择报告入口和 PDF 文件，并将所选文件同步到缆审智核。当一个业务包含多个报告入口或多个附件时，用户可先核对申请编号、任务号、文件名和文件类型，再决定上传内容。

## 主要功能

- 识别待审核和审核未通过的报告入口。
- 在多入口、多文件场景中选择需要同步的 PDF。
- 标记疑似报告、其他附件和疑似收费文件，供用户核对。
- 按申请、试验任务和报告类别同步，由服务端进行内容去重与版本管理。
- 支持当前页任务批量采集和分项结果查看。
- 辅助读取企业查询页面中可见的企业名称、登记状态和统一社会信用代码。

## 安装

1. 在 Edge 地址栏输入 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录 `browser-extension/edge-report-sync/`。

## 连接审核系统

1. 管理员在缆审智核的“系统设置 → 浏览器同步”中生成一次性配对码。
2. 打开扩展，填写审核系统地址和设备名称。
3. 输入配对码完成配对。

审核系统需要提供浏览器同步接口。地址发生变化时，可在扩展中更新服务器地址。

## 同步报告

### 单个业务

1. 进入报告业务页面并打开扩展。
2. 如果检测到多个报告入口，核对申请编号、任务号和状态后选择其中一个。
3. 进入详情页，在有效文件列表中勾选需要同步的 PDF。
4. 确认文件后开始同步。未勾选的附件不会上传。

### 当前页批量同步

1. 在任务列表页打开扩展，选择“当前页批量上传”。
2. 扫描当前已加载的任务，核对识别数量与原页面。
3. 取消不需要处理的任务，再开始采集和上传。
4. 保持批量页面打开，直到所选任务全部返回结果。

扩展仅处理当前页已加载的内容，不会自动翻页。上传成功只表示文件已被系统接收，不代表审核通过。

## 企业状态辅助核验

1. 管理员在系统中生成企业核验批次。
2. 用户在 Edge 中正常登录企业查询平台。
3. 在扩展中开始或继续当日核验。
4. 扩展仅在企业全称精确一致时回写结果；遇到验证码、登录失效或查询次数耗尽时会暂停。

## 隐私边界

- 扩展不申请 `cookies` 权限。
- 扩展不导出登录 Cookie，不读取 USB 密钥或证书私钥。
- 扩展不绕过验证码、访问控制或平台的查询次数限制。
- 只应将报告同步到组织允许使用的审核系统。
